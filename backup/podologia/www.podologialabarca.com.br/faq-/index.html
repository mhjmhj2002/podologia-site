FAQ

O tratamento é dolorido

Essa é a pergunta mais frequênte das pessoas que têm pouco conhecimento sobre a podologia. A verdade é que a podologia é uma técnica utilizada para resolver o problema que a pessoa padece causando o minimo de dor possivel (dor suportável), principalmente no caso de unhas encravadas que seria uma das afeções que mais causam dor, se formos comparar entre as afeões que acometem os pes.
